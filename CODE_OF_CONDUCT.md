# Code of Conduct

By participating in this project you agree to keep discussion constructive and respectful.

## Our standard

Behavior that makes this repository unwelcoming is not tolerated, including: harassment, discriminatory language, personal attacks, publishing others' private information without consent, trolling or sustained disruption, and sexualized language or imagery.

Expected behavior: disagree with ideas, not people; assume good faith; keep critique specific and technical; accept correction gracefully.

## Scope

Applies to the repository, its issue tracker, pull requests, and any project space (including representing the project publicly).

## Enforcement

The maintainer ([bioassembly](https://github.com/bioassembly)) may edit, remove, or moderate contributions that violate this policy, up to banning repeat offenders. Moderation decisions are explained when asked.

Report problems privately via [GitHub Security Advisories](https://github.com/bioassembly/opencode-sage/security/advisories) or privately to the maintainers at bioassembly. Reports are handled confidentially.
